LINUX BASICS RESOURCES.
Welcome to the RedWolf Studios Linux Basics resource Repository.

This Repository contains generic Bash scripts, Command Examples, Reference Documents, ans supporting material for my Linux Basics and other Linux Based Video Series.
The ultimate goal is to create a central location for information, tools, and knowledge gained through research and experience of the production of these episodes, and experimentation within the Home lab.
REPOSITORY CONTENTS :
- Scripts : Generic scrips and practical examples.
- Documentation : supporting notes and technical explanations that dive deeper than the videos.
-Commands : Most of the Documentation contains example commands and basic overviews that can help one gain experience working with Linux Systems.

PURPOSE:
This is intended to provide both viewers and those who come across it practical resources they can download, study, modify to suit their needs, and eventually use on their own Linux Systems.

NOTE: All of these examples are intended for Educational Reasons. Always review scripts and commands before running them. NEVER blindly run a command!
